## English

Give the skill a competitor URL and it runs the Gingiris teardown loop: positioning & value-prop extraction, pricing-page archaeology, traffic/channel signals, and Wayback-based website evolution (keep snapshots only when >20% changed). Output is a structured teardown report you can drop straight into a strategy doc.
